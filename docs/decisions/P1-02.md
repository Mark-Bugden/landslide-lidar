# P1-02 decisions: frozen config and pre-registration draft

## Config layout

- **Decision.** `configs/landslide.json` holds every Appendix B key and value unchanged. Three keys differ, as the
  brief allows: `name` (`landslide_lidar_replication`), `status` (DRAFT until P1-16 sets it to FROZEN) and `paths`
  (our layout, informational only; `src/landslide/paths.py` resolves every file). One block is added:
  `replication`.
- **Evidence.** [E] `tests/test_config_appendix_b.py` embeds Appendix B verbatim, checks every leaf value and type,
  and fails when one is changed (checked by setting `train.lr` to 0.0004).
- **Deviation?** No.

## D02 · The `replication` block (our fixed choices where Appendix A/B is silent)

| Key | Value | Used by |
| --- | --- | --- |
| `seed` | 2611 | Base seed for replication-only random steps that Appendix B doesn't seed (provenance draw, smoke subset, NMS jitter, random baseline). Sampling steps use `sampling.seed` (11). |
| `streams` | `provenance_sample` 1, `positive_points` 2, `waterfill` 3, `negative_jitter` 4, `lookalike_points` 5, `matching` 6, `background` 7, `smoke_subset` 8, `nms_jitter` 9, `random_baseline` 10 | `landslide.config.rng_for(cfg, seed, name)` → `default_rng(SeedSequence([seed, id]))` |
| `provenance.n_sheets` | 12 | P1-03 (the brief asks for at least 10) |
| `negative_jitter_m` | 15.0 | D14: jitter U(−15, 15) m per axis on the 60 m negative grid |
| `nms_jitter_scale` | 1e-9 | Appendix A §9 tie-breaking jitter |
| `verdict_words` | REPLICATED, NOT REPLICATED, INCOMPLETE | D25 |

- **Why.** Each random step gets its own stream, so a change in one step can't shift another's draws. The base seed
  2611 (the date, 26-11) was fixed before any random draw, and no value here was chosen by looking at an outcome.
- **Alternatives.** Reusing Appendix B seeds for unrelated steps (e.g. 2026 for the NMS jitter) would tie unrelated
  draws to one generator; rejected.
- **Open.** Later tasks may need more streams (training shuffles are torch-seeded by P1-06). They are added here
  before the freeze, never after.

  record" are left for P1-16.

  and fixes the replication criteria".
